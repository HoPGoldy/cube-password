# T05: 存量分组密码迁移脚本

## 目标

一次性脚本，把现存 v1 格式（`kdfParams=""`）的 Password 锁分组升级为 v2 argon2id 格式。用完即弃。

## 上下文

- context.md 第 2 节决策 4、第 3 节 migration 与脚本的关系。
- 先例：`scripts/migrate-v1-to-v2.mjs`（自动备份、脏数据跳过、事务写回），沿用其风格。argon2id 在 Node 可直接运行（hash-wasm 同构）。
- 原理约束：服务端无法从 sha512 推回明文，必须 owner 逐组输入旧分组密码、本地验旧 hash 通过后重新派生写回。

## 边界

只允许新增 `scripts/` 下脚本；不改任何源码。脚本行为：自动备份原库 → 查询待迁移分组 → 逐组输入旧密码（本地 `sha512(salt+pwd)` 验证）→ e2ee core 重新派生 → 事务写回三字段；旧密码错误的分组跳过并汇总（保持原数据，可重跑）；结束打印结果清单。

## 验收

对本地库（先自行备份）运行：正确旧密码的分组 kdfParams 非空且 unlock 正常；错误密码分组被跳过且原数据不变；备份文件生成。
